# PDF 证据重排与资料不足回答优化

本轮按可演示的半通用 RAG 应用推进，未增加器械型号目录或新的管理页面。完成了本地 PDF 重排、有限的证据不足规则，以及提示词和评测工具更新，并同步到本机演示服务。

## 实现

1. **正文重排**：排除生成的文件名／页码头部，从候选正文的 640 字符窗口中计算词项覆盖，结合候选集词项频率、常见中英文属性词、数值单位、向量距离和融合候选顺序评分。一般每个子问题最多保留 3 个互补片段，整次上下文仍最多 5 个。无需新增模型或额外模型请求，未改变已有文件权限、弱匹配阈值和页审核过滤。FAQ 继续走原来的选择器。
2. **证据不足规则**：公开问答与发布前评测共用 `evidence_reply()`。对明显缺失按键／菜单图标的 PDF 操作问题，直接提示无法确认完整操作；对只检出临床研究期限、却被问及设备最长使用期的情况，提示不能据此确定设备能力。这两个可识别场景不调用生成模型，仍保留来源供核对。其他情况仍流式生成。
3. **生成约束**：要求区分研究观察期、设备寿命、单次／每日治疗和关机超时；不补写缺失的按键图标，不在宣布资料不足后补充通常值；保留原文“实际疗程由处方医生决定”等限定，未知安全性不得直接改写为不安全。

内部候选 trace 新增 `pdfRerankScore`，可检查最终选择原因。模型规则仍存在语言覆盖和误判边界，不是通用事实核验器。

受控回答 5 题中，临床期限与缺失图标题走确定性提示，另外 3 题调用真实生成模型。没有将规则返回伪称为模型生成。三道原始漏选题（中文问英文每日时长、中文百分比范围、英文特定条件下的基础率限制）均已选入标注页。测试中使用的规则与词项没有硬编码这些题目的预期数值。

最终原始索引诊断的候选证据 Recall@5 为 14/15，Recall@16 为 15/15；本地重排后最终为 15/15。本次顺序检索耗时 P50/P95 为 384.3/488.4 ms，包含真实查询 Embedding；不能据此推导并发吞吐或性能提升比例。

开发过程中真实回答曾出现补写未研究人群、把未知安全性写成不安全、遗漏处方条件，以及在声明不足后继续引用研究换算值等失败。保留了中间报告；针对原因修改提示词、增加有限后端规则后复测，没有删除失败样例或降低事实题标签要求。另修正了新评分器把否定示例视作操作指令、把“不能据此确定”漏识别为拒答，以及超时测试误把同页其他治疗片段一并传入的问题。

## 仍然保留的限制

三份手册仍处于 `pending_review`，未发布；正常页审核规则下目标证据命中仍为 3/15，因为另外 12 道题的标注页还被页审核规则排除。原始索引诊断仅在临时副本中移除该过滤，不可作为上线后的问答准确率。

跨器械名称识别按本轮约定暂缓。不同器械问题不误选当前文件片段的检查仍为 3/12；返回片段仍属于所选文件，未观察到跨文件越权返回。长手册 `--strict` 因上述既有审核／跨器械检查返回 1，不能宣称整体发布门禁通过。

15 道事实题只覆盖少数标注页；存在其他页面重复提供同一事实的可能。关键词与规则检查不能替代逐条事实核对，也不能证明新手册上的总体准确率。
