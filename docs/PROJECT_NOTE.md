# 项目说明

本项目基于Python、FastAPI、PostgreSQL/pgvector和Vue 3构建，以公开医疗器械说明书为演示语料，实现资料上传、解析分块、向量化、混合检索及SSE流式问答。围绕资料处理与维护，实现分片上传、断点续传、持久化任务队列及独立Worker，通过租约、心跳、失败重试和提交校验提高处理可靠性；检索采用向量与关键词双路召回、RRF融合及规则筛选，结合角色权限、资料授权和版本审核控制访问范围。

系统进一步实现受限工具调用式资料预检Agent，以及用户反馈、证据核实、候选版修复、回归评测和审批发布的知识改进闭环。随附源码供技术评审，重点展示模型接入、业务开发、前端交互与问题定位能力。历史测试条件和限制单独记录，不将软件检查通过率视为医学准确率；项目不构成诊疗建议或医疗安全认证。
